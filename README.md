# 💰 Expense Tracker Pro

A modern and responsive Expense Tracker application built using **HTML, CSS, and JavaScript**. This application helps users manage their income and expenses efficiently with real-time balance calculation, transaction filtering, dark/light mode support, and persistent data storage using LocalStorage.

## 📌 Project Overview

Expense Tracker Pro is designed to provide a simple and intuitive way to track daily financial activities. Users can add income and expense transactions, categorize them, search and filter records, edit existing entries, and view a financial summary instantly.

The application stores all transaction data in the browser using LocalStorage, ensuring that data remains available even after page refreshes.

## ⚙️ How It Works

### Adding a Transaction

1. Enter transaction title
2. Enter amount
3. Select transaction type
4. Select category
5. Choose date
6. Click "Save Transaction"

### Editing a Transaction

1. Click the Edit button
2. Update information
3. Save changes

### Deleting a Transaction

1. Click Delete
2. Transaction is removed instantly

### Searching & Filtering

* Search by transaction title
* Filter by category
* Filter by income or expense
